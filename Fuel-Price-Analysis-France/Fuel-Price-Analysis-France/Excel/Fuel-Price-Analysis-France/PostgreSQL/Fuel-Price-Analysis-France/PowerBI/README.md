# Power BI Dashboard

This part of the project focused on transforming SQL analysis into interactive dashboards and visual insights using Power BI.

---

## Dashboard Objectives

The dashboard was designed to:
- analyze fuel price evolution
- compare diesel and SP95 prices
- identify regional disparities
- monitor fuel price volatility
- visualize trends over time

---

## Main Visualizations

### KPI Cards
- average SP95 price
- average diesel price
- fuel price difference

---

### Evolution Analysis
- SP95 vs diesel line chart
- monthly fuel comparison
- fuel price trend analysis

---

### Regional Analysis
- regional fuel price comparison
- interactive mapping analysis
- regional filtering

---

## Key Insight

Diesel prices became higher than SP95 starting March 2026.

This trend may reflect increased transportation pressure and geopolitical supply chain disruptions.

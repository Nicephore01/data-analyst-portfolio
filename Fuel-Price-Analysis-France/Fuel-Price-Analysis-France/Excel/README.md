# Excel Preparation Workflow

Excel was used as the first preparation layer before integrating the datasets into PostgreSQL.

---

## Main Excel Operations

### Initial Dataset Inspection
- quick dataset exploration
- CSV verification
- structure validation

---

### Preliminary Formatting
- removing unnecessary columns
- renaming columns
- preparing datasets for SQL integration

---

## Objective

The goal of this step was to ensure that the datasets were clean, structured, and ready for PostgreSQL transformation and analysis.

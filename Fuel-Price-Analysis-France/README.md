# Fuel Price Analysis in France (Feb – Apr 2026)

## Project Overview

This project analyzes fuel price evolution in France between February and April 2026 during geopolitical tensions in the Middle East.

The goal was to identify:
- fuel price trends
- diesel vs SP95 evolution
- regional disparities
- potential economic impacts on transportation and logistics

---

## Tools Used

- Excel
- PostgreSQL(pgAdmin)
- Power BI
- Canva (data storytelling)

---

## Project Workflow

### 1. Data Collection
Fuel price datasets were collected on data.economie.gouv.fr for:
- February 2026
- March 2026
- April 2026

---

### 2. Initial Data Preparation (Excel)

Excel was used for:
- preliminary dataset exploration
- CSV verification and formatting
- removing unnecessary columns
- standardizing column names
- validating data structure before PostgreSQL integration

  
---

### 3. Data Cleaning (PostgreSQL)

Tasks performed:
- data type conversion
- null value handling
- table restructuring
- merging datasets
- duplicate verification

---

### 4. Data Analysis (PostgreSQL)

Main KPIs:
- average fuel prices
- fuel price difference
- regional price comparison
- fuel volatility
- diesel vs SP95 evolution

---

### 5. Data Visualization (Power BI)

Interactive dashboards were created to:
- compare fuel prices
- analyze regional trends
- visualize fuel evolution over time
- build mapping analysis

---

## Key Insight

Diesel prices became higher than SP95 starting March 2026.

This supports the idea that fuel price increases may be structural rather than temporary.

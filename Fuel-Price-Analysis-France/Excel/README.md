# Excel Preparation Workflow

This folder contains the initial data preparation steps performed in Excel before integrating the datasets into PostgreSQL.

---

## Objectives

The Excel phase was used to:
- inspect raw datasets
- verify CSV structure
- prepare files for SQL integration
- identify formatting inconsistencies

---

## Main Excel Operations

### Initial Dataset Inspection
- checking column consistency
- verifying missing values
- validating fuel price columns

---

### Preliminary Formatting
- removing unnecessary columns
- renaming columns
- reorganizing datasets
- preparing clean CSV exports

---

## Workflow Purpose

This preparation step ensured that the datasets were structured and ready for PostgreSQL cleaning, transformation, and analytical processing.

---

- Microsoft Excel

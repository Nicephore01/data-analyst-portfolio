# Power BI Dashboard & Data Visualization

This folder contains the Power BI dashboards created from the cleaned PostgreSQL datasets.

---

## Dashboard Objectives

The dashboard was designed to:
- monitor fuel price evolution
- compare SP95 and diesel prices
- identify regional disparities
- visualize fuel price volatility
- support data-driven insights

---

## Main Dashboard Features

### KPI Cards
- average fuel price
- most expensive fuel region
- cheapest fuel region
- fuel price gap analysis

---

### Visualizations
- fuel price evolution line charts
- SP95 vs diesel comparison
- Average price for SP95 and diesel
- regional fuel price analysis

---

### Mapping Analysis
Interactive regional mapping was implemented to:
- visualize regional price disparities
- identify high-price regions
- compare fuel prices geographically

---

Excel → PostgreSQL → Power BI
